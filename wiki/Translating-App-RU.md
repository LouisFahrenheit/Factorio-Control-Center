# Перевод интерфейса панели (FCC)

Если вы хотите помочь с переводом веб-панели на новый язык или улучшить существующие тексты, в этой статье описана структура файлов локализации. Спасибо за ваш вклад в развитие проекта!

> [!NOTE]
> Руководство по переводу документации и статей Wiki доступно в разделе [Добавление переводов в Wiki](Translating-Wiki-RU).

---

## Статус языков

Файлы локализации находятся в каталоге `locale/server_lang_*.json` и отображаются в **Настройки пользователя → Язык**.  
Английский файл (`server_lang_en.json`) является эталонным: все остальные файлы должны содержать **ровно тот же набор ключей**.

| Код | Язык | Файл интерфейса | Файл команд | Статус |
| :--- | :--- | :--- | :--- | :--- |
| `en` | English | `server_lang_en.json` | `server_commands_en.json` | Эталон |
| `ru` | Русский | `server_lang_ru.json` | `server_commands_ru.json` | Полный перевод |

Для языков **`de`, `fr`, `es`, `ja`, `zh`, `pl`, `pt-br`, `uk`, `ko`, `it`, `cs`, `tr`, `nl`**: достаточно создать файл `locale/server_lang_XX.json` и перевести его. Названия этих языков уже встроены в меню выбора и не требуют правок в коде.

Если нужного языка нет в списке, создайте Issue или Pull Request для добавления названия в меню (`lang_name_*`).

---

## Добавление нового языка интерфейса

1. Скопируйте эталонный файл:
   ```text
   locale/server_lang_en.json  →  locale/server_lang_XX.json
   ```

2. Переводите **только значения** (текст справа) — сами ключи (слева) должны оставаться строго на английском.

3. Проверьте корректность локализации:
   ```bash
   npm run locale:check
   ```

4. Проверьте отображение в панели: **Настройки пользователя → Язык**.

5. Отправьте Pull Request или передайте готовый файл `server_lang_XX.json` автору проекта.

## Каталог команд (опционально)

Во вкладке **Команды** доступен встроенный каталог RCON-шаблонов (названия и описания).  
Панель объединяет `server_commands.json` с `server_commands_<code>.json` для выбранного языка. Если языковой файл отсутствует, используются английские названия.

### Перевод команд

1. Скопируйте `server_commands_en.json` → `server_commands_XX.json`.
2. Переведите **значения** в разделах `categories` и `commands` — не изменяя ключи.
3. Не редактируйте сами RCON-шаблоны в `server_commands.json`, если вы не меняете логику команды.

### Добавление новых команд

Вы можете предложить новые предустановленные RCON-команды:

1. Откройте **Команды** → **Редактор команд** в панели.
2. Создайте команду, настройте параметры и протестируйте её на сервере.
3. Отправьте готовые файлы через Pull Request.

## Соглашения по именованию ключей

| Префикс / шаблон | Назначение |
| :--- | :--- |
| `web_*` | Авторизация, доступ, веб-панель |
| `instances_*` | Список серверов и мастер создания |
| `saves_manager_*` | Управление сохранениями |
| `modpack_*`, `mods_*` | Моды и модпаки |
| `map_gen_*` | Генератор карты |
| `players_*`, `history_*` | Игроки и история |
| `server_settings_*` | Редактор `server-settings.json` |
| `maintenance_*` | Расписание обслуживания |
| `api_error_*` | Ошибки API |
| `web_error_*` | Сетевые ошибки панели |

**Подстановки (плейсхолдеры):** сохраняйте оригинальный формат без изменений:
- `{0}`, `{1}`, … — порядковые аргументы (интерфейс)
- `{}` — последовательные аргументы (логи и серверные строки)

## Проверка файлов

| Команда | Описание |
| :--- | :--- |
| `npm run locale:check` | Проверяет отсутствие или избыток ключей по сравнению с английским файлом |
| `npm run locale:check:unused` | Проверяет наличие неиспользуемых ключей в коде проекта |

## Советы переводчикам

- Делайте надписи интерфейса краткими — многие элементы отображаются в узких таблицах и кнопках.
- Сохраняйте символы переноса строк `\n` — они используются для форматирования диалогов и ошибок.
- Не переводите названия продуктов: **Factorio**, **FCC**, **RCON**, **Space Age**, а также расширения файлов (`.fcc`).
- Названия игр и модов в кавычках передаются через плейсхолдеры `{0}`.
- После правок обязательно выполните проверку `npm run locale:check`.
