# Добавление переводов в Wiki

Репозиторий поддерживает мультиязычную документацию в GitHub Wiki. Любой участник сообщества может добавить перевод на новый язык, добавить новую страницу или обновить существующие. Спасибо за ваш вклад в развитие проекта!

> [!NOTE]
> Руководство по переводу интерфейса самой веб-панели доступно в разделе [Перевод интерфейса панели](Translating-App-RU).


---

## Правила именования файлов

Для языковых версий страниц используется суффиксная схема:

- **Английский (базовый язык):** `<Page-Name>.md` (например, `Installation-Guide.md`)
- **Русский язык:** `<Page-Name>-RU.md` (например, `Installation-Guide-RU.md`)
- **Другие языки:** `<Page-Name>-<LANG>.md`, где `<LANG>` — двухбуквенный код языка в верхнем регистре (ISO 639-1):
  - Немецкий: `Installation-Guide-DE.md`
  - Французский: `Installation-Guide-FR.md`
  - Испанский: `Installation-Guide-ES.md`
  - Китайский: `Installation-Guide-ZH.md`

---

## Структура страницы

Каждая страница должна соответствовать следующим требованиям:

1. **Панель переключения языков:** В самом верху страницы размещаются ссылки на другие языковые версии:
   ```markdown
   [English](Page-Name) | [Русский](Page-Name-RU) | [Deutsch](Page-Name-DE)

   ---
   ```
2. **Текст статьи:** Точный перевод оригинального содержания страницы.
3. **Обновление бокового меню:** Добавьте ссылку на страницу в [`_Sidebar.md`](_Sidebar) в блок соответствующего языка.
4. **Обновление главной страницы:** Добавьте ссылку на раздел в [`Home.md`](Home) и [`Home-RU.md`](Home-RU).

---

## Отправка изменений

1. Сделайте Fork репозитория: [Factorio-Control-Center](https://github.com/LouisFahrenheit/Factorio-Control-Center).
2. Создайте или измените файлы в папке `wiki/`.
3. Создайте Pull Request в ветку `main`.
4. После слияния PR GitHub Actions автоматически обновит страницы в GitHub Wiki.
